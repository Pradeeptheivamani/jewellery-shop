# 💍 Jewellery Shop Website

A simple jewellery shop webpage built using **HTML and CSS**.  
This project is beginner-friendly and suitable for students learning basic web development.

## 📌 Features
- Attractive header with shop name
- Navigation menu (Home, Necklaces, Rings, Earrings, Contact)
- Jewellery product cards with price
- Clean and simple design
- Single HTML file (easy to understand)

## 🛠️ Technologies Used
- HTML5  
- CSS3
